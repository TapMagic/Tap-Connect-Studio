1. Read `07_MANIFEST_AND_RULEBOOK/CABINET_NOIR_RULEBOOK.md`.
2. Read `08_CODY_HANDOFF/CODY_IMPLEMENTATION_HANDOFF.md`.

## Core rule

**Do not redraw, regenerate, mirror, flatten, or reinterpret certified Cabinet Noir furniture.** Studio composes certified assets and overlays live content according to the contracts in the rulebook.

## Folder map

- `01_PRODUCTION_ASSETS/` — core furniture and standalone masters.
- `02_STRUCTURAL_SYSTEM/` — modular runtime structure for variable-height stacks.
- `03_PLUGS_SEMANTIC/` — semantic/system plug drawer.
- `04_PLUGS_SOCIAL_SYSTEM/` — platform/social plug drawer.
- `05_TOPPER_VARIANTS/` — circular identity crown furniture variants sharing one socket contract.
- `06_CERTIFIED_PRESETS_REFERENCES/` — approved full-stack presets/references; **not** the preferred runtime composition mechanism.
- `07_MANIFEST_AND_RULEBOOK/` — source of truth for family behavior.
- `08_CODY_HANDOFF/` — implementation instructions and acceptance criteria.
- `99_SUPERSEDED_DO_NOT_DEPLOY/` — quarantined old/duplicate assets.

The Google G asset was supplied as `CN-36...`; it is normalized here as **CN-036** so the production catalog has a stable three-digit ID.
