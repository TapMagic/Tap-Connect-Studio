# File Format Capability Matrix

Registries: `FileFormatRegistry`, `IngestionFormatRegistry`, `ExportFormatRegistry` in `lib/fusion/formats`.

Unsafe executables are rejected/quarantined. Rights, privacy class, scanning, limits, conversion, preview, metadata, retention, entitlement apply.

## Images (ingest / library / AI / export where noted)

PNG, JPG/JPEG, WebP, GIF, SVG, AVIF, HEIC/HEIF, TIFF, BMP, ICO

## Video

MP4, MOV, WebM, M4V; MKV/AVI via conversion where practical

## Audio

MP3, WAV, M4A, AAC, FLAC, OGG/Opus

## Documents

PDF, DOCX, DOC (convert), ODT, RTF, TXT, Markdown, HTML, EPUB, EML/MSG/MBOX where applicable

## Slides / design

PPTX, PPT (convert), ODP, KEY (convert), images/PDF/SVG exports

## Data

XLSX, XLS (convert), ODS, CSV, TSV, JSON, JSONL, XML, YAML, ZIP

## Contacts / calendar

VCF, ICS

## Fonts (licensed)

TTF, OTF, WOFF, WOFF2

## Sources

URLs, websites, sitemaps, RSS/Atom, authorized social/video/provider objects, APIs/webhooks/cloud imports

## Exports

PNG/JPG/WebP/SVG/PDF/MP4 · HTML/CSS package · hosted publication · embed · QR · CSV/XLSX/JSON/JSONL/ZIP · VCF/ICS · email HTML/plain/MJML/provider packages · Apple/Google Wallet objects · reports PDF/CSV/XLSX/JSON/PNG · scheduled email · secure share · API/webhook

## Visual-reference reconstruction inputs

Screenshot, image, PDF, webpage URL, brochure, slide, design export → editable registered sections/blocks with rights warnings and undo.
