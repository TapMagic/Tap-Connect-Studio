# Canonical Glossary

Status: proposed canonical vocabulary for human review
Evidence base: repository at `d67d1399a064834d476a0675642c294cf13478e3`

Actions are `KEEP`, `RENAME`, `MERGE`, `RETIRE`, or `INTERNAL ONLY`. “Affected paths” are representative, not exhaustive; the current product map carries the expanded code map.

| Current / alternate names found | Canonical name | Definition | Area / audience | Action | Affected paths |
|---|---|---|---|---|---|
| TapConnect; Tap Connect; Tap Card; vCard; digital card | **TapConnect Card** (short: **Card**) | The living customer-facing business destination and product center. “TapConnect” may name the product/company; an individual customer object is a Card. | Core / customer + Owner | MERGE | `components/tap/**`, `components/card/tap-card-builder.tsx`, `app/dashboard/card/**`, `lib/brand/tap-card.ts` |
| Studio; Dashboard; Owner OS | **TapConnect Studio** (short: **Studio**) | The Workspace operating system for ordinary Owner work. | Core / Owner | RENAME “Dashboard” in visible IA where it means Studio | `app/dashboard/**`, `components/dashboard/**`, `components/studio/**` |
| Control; Platform Admin; Admin; TapMagic Platform Admin | **Control Room** | Internal platform governance, not business-content editing. | Governance / platform admin | MERGE; keep “Platform Admin” as role adjective only | `app/control/**`, `components/control/**`, legacy `app/admin/**` |
| Workspace; Business; tenant; account | **Workspace** for operating boundary; **Business** for business facts/entity | Workspace is the controlled tenant context; Business is its organization/fact record. | Tenancy / Owner + admin | KEEP both with distinct meanings | `Business`, `BusinessUser`, `WorkspaceKind`, `lib/workspace/context.ts` |
| Demo; Demo Workspace; fixture; sandbox; mock | **Demo Workspace** | A real Studio Workspace with server-enforced Demo safety. | Experience; Journey; TapFlow | **Experience** as product category; **Journey** as multi-step Experience; **TapFlow** only if retained as the Journey runtime/engine name | Reusable customer outcome; Journey is an ordered multi-step form. | Studio / Owner | MERGE product IA; INTERNAL ONLY for engine jargon | `app/dashboard/experiences/**`, `lib/fusion/journey/**` |

## Naming decisions still requiring Owner approval

1. Whether TapCast and TapLoop remain customer-facing branded capability names or become Distribution and Loyalty.
2. Whether “TapProof” survives as an evidence-quality badge inside Insights; it must not replace Tap Trace.
3. Whether legacy `/dashboard/devices` remains as a compatibility alias only after all visible language becomes Tap Points.
4. Whether “Campaign Workbench” remains the Campaign editor name or is simplified to Campaign Editor.
5. Whether legacy `/admin` landing CMS moves under Control Room or remains a separately named internal tool.
