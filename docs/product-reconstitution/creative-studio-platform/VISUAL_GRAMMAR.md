## Foundational laws

1. **Visual Parts belong to Studio**, not the first object that uses them.
2. **Decomposition Parity:** reassembling approved parts must not materially reduce visual quality. Reuse never outranks fidelity — keep composite parts when further split would harm quality.
3. **Visual recipes must not invent business content** (Action, wording, identity uploads, destinations).
4. **Mobile-first:** phone viewport is the primary customer-facing composition target.
5. **Background ≠ Surface ≠ Mount ≠ Action.** Mood / staging / purpose stay separate.
6. **Icon Station:** geometry ≠ backing ≠ rim ≠ content ≠ accent. Scale and anchor are Host layout fields, not Signature styling.

## Depth relationship model

Levels 0–5: Page → Surface → Mount → Core Action → Icon Station → Accent.
