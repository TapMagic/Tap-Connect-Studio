## Cross-reference synthesis

### Patterns adopted

- A compact document bar, narrow permanent rail, one layered drawer, dominant pasteboard, and a small contextual toolbar.
- Visual browsing for Elements, Buttons, Brand resources, Assets, Backgrounds, fonts, colors, Projects, and output profiles.
- Controls appear only when the selected object advertises the relevant capability.
- AI work is scoped, reversible, and shown beside the live editable document.
- Resize/Adapt is a named top-bar task with explicit output dimensions and source-preserving copy semantics.

### Deliberate TapConnect differences

- TapConnect retains dark operational styling and its own visual language; editor appearance is a personal view preference and never edits document colors.
- A Tap Card remains a governed responsive functional document, not a generic multi-size artboard.
- Action, QR, Campaign, tracking, consent, and publication identities are protected functional bindings. Visual edits and AI proposals cannot silently replace them.
- Unconfigured providers and unfinished data/media capabilities are hidden or shown as disabled setup states instead of optimistic controls.

## Starting architecture and retirement map

| Concern | Canonical starting path | Completion decision |
| --- | --- | --- |
| Document mutation/history/autosave | `TapCardBuilder` live model → composition/Section patch → labelled history → recovery journal → draft save | Preserve and require SelectionRef validation at the capability boundary. |
| Canvas/rendering | `CreativeCompositionCanvas` plus shared Preview/public rendering contracts | Preserve one renderer; extend canonical primitives/capabilities rather than creating a second canvas. |
| Ordinary selection tools | `CardContextualObjectToolbar` | Promote to primary interface and route focused tasks into the one left drawer. |
| Legacy Inspector | `CardComposerInspector`, mounted by `CardAuthoringWorkspace` for most active tool IDs | Retire from ordinary Edit Mode; retain only narrowly scoped compatibility code until no advanced field depends on it, never mounted as ordinary authority. |
| Rail/drawer | `CardCreativeToolRail`, `AdaptiveWorkspaceShell`, `CardShellToolDrawer` | Consolidate into one predictable layered drawer and retain scroll/selection/focus. |
| Assets | `SharedMediaAssetBrowser`, `MediaPicker`, `lib/media/*` | Reuse as the one Asset authority and normalize provider metadata. |
| Brand | Brand inheritance plus `BrandDrawer` and Brand services | Keep Brand authoritative; select individual resources without applying the full kit. |
| Publication | Existing Card draft/public lifecycle and revision APIs | Preserve; Creative Studio edits draft only and never introduces a second publication path. |
