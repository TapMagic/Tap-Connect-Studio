# Preset Pack Roadmap

Status: documented for later waves — not fully built in this pass.

## Architecture preserved now

- Versioned starter registry (`starter` pack, version 1)
- Canonical Elements only
- Universal Editor insert paths unchanged
- Future packs register as additional collections

## Future TapConnect design packs

| Pack | Intent |
| --- | --- |
| Retail Pack | Price, offer, product spotlight, claim CTAs |
| Restaurant Pack | Menu, hours, reservations, directions |
| Events Pack | Tickets, RSVP, calendar, VIP |
| Professional Services Pack | Contact, consult, trust, appointment |
| Seasonal Packs | Holiday and campaign seasons |
| Luxury Materials Pack | Metallic, foil, glass Surfaces and Text |
| Playful Family Pack | Soft shapes, fun Badges, kid-friendly CTAs |
| AI-generated Brand Packs | Brand-derived proposals through governed AI |

## Non-goals for this pass

- Do not block launch on exhaustive original catalog
- Do not invent a parallel preset engine
- Do not flatten presets into non-editable artwork
