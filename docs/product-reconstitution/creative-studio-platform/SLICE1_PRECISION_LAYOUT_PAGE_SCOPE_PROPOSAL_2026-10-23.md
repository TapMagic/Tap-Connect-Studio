## Recommended correction: Frame and Page Truth

The smallest coherent Slice 1 correction is to repair the shared frame operation, its existing UI consumers, page-height semantics, and the demonstrated Curated size binding. Discovery improvements accompany each repair. This proposal does not reopen a general UI redesign or implement Slice 2.

1. **Record current geometry and capabilities.** Capture root/nested fixtures at desktop and 390px, including exact parent content boxes, padding/borders, selected scope, overflow policy, authored/effective dimensions, and recipe sizing policy. Preserve the existing PO fixtures; use a separate local test copy after approval.
2. **Repair the existing geometry authority.** Frame resize receives the existing document, target, requested frame, measured parent/content boxes, and declared operation intent. It returns the complete document change plus effective constraints. For a Layered content box, retain eligible child local pixel coordinates and sizes by rebasing normalized fractions. Rebase each affected relationship once; do not rescale all descendants indiscriminately. Keep authored angles, styles, text, actions, identities, and parent membership intact. Check persistence normalization and minimums so rebasing cannot be silently clamped on save. Preflight impossible requests atomically.
3. **Connect every existing sizing consumer.** Pointer resize, numeric Inspector, Match dimensions, parent/root extent changes, and explicit clipboard expansion use the same frame semantics and complete canonical transaction. Group resizing continues through the existing Group scaling contract. Duplicate/copy/paste must preserve the resulting geometry and remap identities as before. Fix selection-reference ambiguity: use the existing primary-selection identity, visibly label the reference, and keep it stable for the transaction. Never infer the reference from array order.
4. **Repair capability discovery.** Expose Position/Size for the outer Curated module alongside Edit Contents. Flow exposes supported width/proportional sizing; Layered retains appropriate handles and exact fields. Make Horizontal and Grid available in the immediate Container layout controls. Keep “Placement in parent” separate from “Inside this Container.” Preserve legacy alignment data when separating its meanings; no silent migration of existing appearance. Existing numeric rotation and Reset stay reachable in the same placement context.
5. **Repair the existing Curated text-size binding.** Keep one recipe/typography authority. Define requested size at its documented reference scale, derive responsive effective size, and display any constraint. Remove inert parts of the exposed range or repair their mapping within certified limits; do not increase certification limits or silently alter existing default rendering. Slider and numeric input share the same validated action command, including keyboard commit/cancel. Verify native Text and standard Button size controls as related consumers; do not implement new Text transaction or rendered-bounds semantics under this step.
6. **Reconcile page extent consumers.** Use the existing card-extent authority as the common result for requested minimum, measured required extent, and actual output height. Keep the Layered coordinate plane explicitly distinct from public-page minimum. Route intentional plane resizing through the repaired frame operation; do not normalize children against a minimum that does not define their coordinate space. Fit measures publishable layout and transforms, clips descendant extents according to declared overflow, includes explicit bottom padding, and excludes editing chrome. Report effect-envelope estimates honestly; use conservative fallback where exact paint bounds are unavailable. If Fit cannot safely reduce height, retain it and explain the blocker. Preview and commit must use identical calculations.
7. **Verify and document before returning for acceptance.** Focused authority tests plus native interaction, screenshots, saved-document checks and Preview comparisons. Report failed or blocked automation individually. Push only the intended documented result and appropriately isolated code after implementation verification; preserve unrelated WIP. Slice 1 closes only on PO hands-on approval.

### Geometry and scope decisions

- **Frame resize** changes the Container boundary. Eligible Layered children retain their local content-box pixel frames; Flow children retain declared sizing and reflow only as their existing layout rules require. Relative/stretch constraints are explicit exceptions, not hidden behavior.
- **Rotation** remains about the frame center. Pointer resize retains the existing opposite edge/corner convention in local axes. Children follow only the resulting parent transform; no additional hidden translation. Padding and borders participate in content-box conversion.
- **Scale Contents** remains distinct from frame resize. Preserve existing Group and certified-module scaling; do not add a general Container scaling feature now.
- **Viewport changes** retain current responsive rules. Authoring-time rebasing does not convert the document wholesale to pixel positioning or invent new responsive anchors.
- **Matching** applies atomically to compatible targets. For a target constrained by aspect ratio, use a supported proportional match only when declared by capability; otherwise disable it with a specific reason. Match Both must not distort a certified assembly. No silent skipping of incompatible targets.
- **Page height** is not one interchangeable number: minimum public extent, actual required content extent, and Layered coordinate-plane height have distinct meanings. Fix the labels and routing before adding new height modes. Shrinking must not clip valid content implicitly.
- **1600px** is a real limitation for a single long-form Layered plane, not proof that all Experiences are limited to 1600px. A future bounded change should centralize the mode-specific limit policy, then raise the approved Layered maximum consistently in validation, normalization, renderer, Inspector, clipboard fitting, and tests. Preserve fractions using the same resize semantics and verify scrolling/performance. No new document engine or migration is justified solely to remove this limit.
- **tApIt** can eventually discover the same permitted operations, preview their complete result, receive constraint explanations, and execute through the same commands/history. No AI UI, service, planner, or separate mutation path is proposed.

## Exact proposed acceptance criteria

All dimensional comparisons below use unzoomed CSS pixels. Allow **0.5px** display rounding, **0.01°** angle comparison, and floating-point serialization tolerance; authored identities, text, styles, actions and parent membership must otherwise remain unchanged unless the operation explicitly targets them.

1. **Text:** native controls change a selected standard Text, standard Button label and permitted Curated action label. For the observed Curated label, exercise 11, 13, 15 and 16 requested px where currently permitted. Every enabled choice changes the effective glyph size at the documented reference width; at narrower constrained widths show the effective size and reason, with no misleading active range. Slider and numeric requested values agree, remain editable, undo in one completed operation, reload correctly, and match Preview. Other labels and exact underlying text remain unchanged. No new Slice 2 text semantics.
2. **Curated scope:** select the whole stack in Flow and Layered, reach supported sizing without entering an internal action, and perform proportional width changes. Certified artwork, internal proportions, labels, Materials, spacing and destinations remain intact. Custom outer-frame sizing, where supported, is explicitly distinguished from scaling its contents. Governed internal structural parts have no unrestricted handles.
3. **Horizontal Flow:** place two stacks in one existing Container using Horizontal or Grid. Set gap 12px and valid widths that fit. They remain side by side after save/reload and Preview. Drag reorders rather than retaining arbitrary X/Y. Declared width/reflow constraints explain insufficient space; wrapping is not falsely advertised. Changing internal alignment must not unexpectedly move the Container within its parent.
4. **Mode changes:** Flow → Layered → Flow → Layered preserves IDs, content, child membership, Materials, actions, order and dormant Layered placement. Initial Flow conversion uses credible placement; returning to Layered restores authored positions. Each completed switch has one history entry.
5. **Rotation:** enter 0°, 45°, 90°, 180° and 270° with existing numeric controls; Reset returns to 0°. Pointer rotation with Shift snaps to 15°. Stored X/Y/W/H stay unchanged when setting only rotation. The center pivot and nested rotation composition match the visible result. Preset buttons and Match Rotation are not required unless separately approved.
6. **Exact dimensions / Match:** set 120px and equivalent percent in a known parent; pointer and Inspector agree on effective Placement. Match Width, Height and Both on compatible sibling Text, images/logos, Containers, ordinary elements and Groups; visibly identify the reference. Aspect-governed targets either use a permitted proportional operation or explain rejection. Reference choice survives selection-order changes; no out-of-bounds or partial silent application. Cross-parent matching remains explicitly unavailable.
7. **Container frame:** in a 200×200px content box, place an eligible child at (20,30), size 80×40px. Grow the content box to 200×300px and then 300×300px by pointer and Inspector. Child remains at (20,30), 80×40px. Repeat with two nested levels, 16px padding, 2px border, a rotated parent, a rotated child, a Group, and clipped/visible overflow. Expected world positions follow the documented parent transform only. Shrink conflicts must constrain/reject or use already-declared clipping with an explicit explanation; never silently scale artwork.
8. **Flow reflow:** increasing height leaves top-aligned children and gaps unchanged; increasing/decreasing width follows actual percentage/stretch/wrapping rules where supported. Mixed Flow-parent/Layered-child and Layered-parent/Flow-child cases use the correct content box. Existing Group scaling remains intentional and undoable.
9. **Page extent:** exact input and bottom-edge drag show the same effective field; preview equals committed state. Fit a page containing nested/rotated items and visible overflow, then repeat with clipping. Selection chrome has no effect on Fit. Explicit bottom padding remains; Fit removes only unnecessary authored blank extent. Shrink cannot silently clip valid content. At existing mode-specific limits, explain refusal without altering geometry. Preserve an intentionally enlarged minimum until the user changes it or invokes Fit.
10. **History and related lifecycles:** each gesture, numeric edit, match, layout switch and Fit is one completed canonical history operation; Escape restores the start. Undo/Redo restores exact identities and geometry. Repeat copy/paste, duplicate, grouping/ungrouping, nesting, image replacement and Material changes around resized parents; no hidden relocation, unintended reparenting or normalization drift. Existing clipboard destination and repeated-paste regressions remain covered.
11. **Parity:** compare Canvas, Inspector, serialized saved document and Preview at the same viewport after each operation and reload. Public rendering authority remains shared; production is not used as a test target. Invalid/unsupported operations cannot appear effective or save partial changes.
12. **Desktop and 390px:** complete the same supported native-control paths at desktop and 390px. Controls remain reachable, focused fields retain keyboard ownership, and IME composition is not hijacked. Inspect computed pointer/touch targets separately from visible handles; report physical-touch testing separately from emulation. Capture before/after screenshots plus interaction steps and measured geometry. Automation failures are BLOCKED/FAILED evidence, never passes.
