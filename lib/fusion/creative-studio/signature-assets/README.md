# Signature asset authority

This family-neutral registry owns premium authored visual families. Customer discovery is permanently organized as `Visual Parts → Signature → Family → Actions / Identity / Dividers / Frames & Stages / Footer`.

Source masters in `public/visual-parts/signature/<family>/source/` are immutable. Runtime rendering may proportionally contain them and layer only declared live sockets. Reference/alternate files are segregated and are never returned by the customer catalog.

Arc Ember's source approval renders for Utility, Team/About, Compact, and Stack Row contain sample copy. Their byte-identical records remain the catalog/provenance authority. The separately supplied blank pristine shell is used as `liveShellAsset` for editable customer output so live text does not collide with baked approval copy. No shell artwork is reconstructed.

The combined two-row reference was deliberately not ingested. Double Stack is the generic `STACK-2` recipe over two independent `stack-row` Action objects.

Arc Ember divider masters are transparent floating parts. The registry must point directly at the supplied PNGs; renderers must not add backing panels or crop their glow padding.

`master/arc-ember/stage/surface/v1` is the one expandable exception to whole-master proportional containment. Its supplied bitmap remains immutable, while the renderer uses its recorded protected-cap insets as a 9-slice: corners, hardware, ornaments, and plinth endpoints remain fixed; straight rails, the authored dark center field, plinth span, and continuous glow runs extend. Independent children are laid out vertically in the protected content aperture, and the Card composition height is derived from their count and intrinsic proportions.
