# TapConnect Signature System v1 — Handoff Pack

This pack contains the 27 individual assets manufactured and approved during the Signature System v1 build.

## Permanent cabinet placement

- Visual Parts → Buttons = Foundation / mundane functional controls
- Visual Parts → Signature → Signature System v1
  - Actions
  - Identity
  - Frames & Stages
  - Dividers
  - Micro Parts

`Micro Parts` is now a permanent Signature subgroup. Future families may leave it empty or populate it as needed.

## Source preservation law

Every PNG in this pack is copied byte-for-byte from the approved source supplied by Product/Design.
No source was resized, recompressed, masked, cleaned, or visually modified during packaging.

Studio may position, proportionally scale, populate declared live sockets, and use approved derived masks/variants.
Studio must not redraw, reconstruct, simplify, or procedurally approximate a finished master.

## Important readiness notes

Four action images contain baked approval copy/identity and are therefore filed under `01_actions/visual-authority/` rather than production:
- 01 Primary Action
- 02 Secondary Action
- 03 Rounded Rectangle Action
- 05 Plaque / Panel Action

They are visual authority only until matching blank pristine shells are supplied. Do not erase the baked content, rebuild them in CSS, or quietly ingest them as editable masters.

The Toggle (#24) is also filed as visual authority because its knob and shell are a single composite bitmap. Runtime state movement requires either separately approved state masters or a certified non-destructive component split.

Electric Rift Stage (#14) and Electric / Energy Divider (#20) are approved default visuals. Color and energy-intensity controls must preserve the source and use safe masks/variants rather than global hue shifting or reconstruction.

## Manual build and tApIt

Signature System v1 must be fully usable manually. tApIt is an optional accelerator, not a required runtime dependency.
Both paths must converge on the same canonical Studio representation.

## No-Enrique rule

If integration requires visually redesigning a master, stop. That means the manufacturing package or the live-socket contract needs another Product/Design pass.
